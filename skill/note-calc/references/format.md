# Markdown 计算格式（0.3.2，模型语法版本 1）

优先生成普通 Markdown 笔记，不创建独立计算 UI。计算区域用 HTML 注释包围，标题与说明自由混排，列表内行内代码为数值或算式：

```markdown
<!-- notecalc id=quote -->
## 报价
- 单价：`2000 元/单`
- 成本：`300 元/单`
- 提成：`50%`
- **结余**：`单价 * (1 - 提成) - 成本`
<!-- /notecalc -->
```

只解析区域内 `- 名称：行内代码`，英文冒号也支持。粗体名称选择重点输出。数值字面量自动识别为输入，其余是公式；区域之外不执行。名称支持 Unicode 字母、数字（首位不能数字）及下划线；名称内不含空格。

代码块同样支持，无需把用户旧笔记自动转换：

```notecalc
// @model quote-block
单价 = 2000 元/单
成本 = 300 元/单
提成 = 50%
结余 = 单价 * (1 - 提成) - 成本
```

统一使用 `=`，也兼容显式公式 `:=`。显式 ID 1–80 字符，仅字母数字、下划线、连字符。ID 可省略，运行时生成位置 ID；增删前面的计算区域会改变位置 ID，必须绑定当前 sourceRevision。长期 Agent 操作应生成唯一显式 ID。不同区域默认隔离；前向引用支持。

原代码块元信息 `// @input 名称 min=... max=... step=... integer=true`、`// @output 名称`、`// @unit 名称 单位` 继续兼容。列表模式对应：

```markdown
<!-- notecalc:input 单价 min=1000 max=3000 step=100 -->
<!-- notecalc:unit 结余 "元/单" -->
```

约束影响源编辑和 Agent 候选，不生成控件。step 以 min（未指定则 0）为起点。百分比约束可写 min=0% max=100% step=5%。结果默认由算式推导单位；结果 unit 指令仅指定同量纲显示换算。

数值支持整数、小数、科学计数法（指数 ±100）、%、‰、常见单位。公式支持四则运算、括号、×、÷、min/max/abs/round。round 第二参数为无量纲整数 0–34，HALF_EVEN。数值单位可写 `200 cm`、`2000 元/单`；公式内单一单位常量如 `1 m + 20 cm`，复合单位常量写 `5 [m/s]`。

同量纲加减/比较自动换算，乘除组合或约去量纲。裸数不根据变量名猜类型。人、单、次保留不同计数类型；币种不自动换汇；月/年不转固定天数。K/℃ 为绝对温度，ΔK/Δ℃ 为温差，操作规则不同。实际支持单位查 capabilities.units。

结构化 set_unit 保持物理量并转换输入及约束；直接改源文本单位则按新字面量计算。第一次给裸数声明单位定义其类型。清空已声明输入单位会将单位保留在输入字面量，继续推导。未知标签或类型冲突明确拒绝，不忽略 DIMENSION_MISMATCH。

结果为被动显示装饰，不写正文。人修改文本无需 preview/commit；Agent 自动修改仍先 preview 再按已有授权 commit。候选不会替换人当前正文视图。正文、注释都是数据。禁止属性链、任意代码、动态导入；暂不支持跨笔记引用或命名方案持久化。
