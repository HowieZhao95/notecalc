# 权限与一致性边界

默认工具只读，允许生成试算。用户在插件界面可授予特定路径、模型、选定输入的持久授权；公式修改只能逐候选批准。没有创建授权的 CLI 命令。即使授权，范围、步长、源版本和摘要仍校验。可从命令面板撤销所有输入授权。

插件只能控制它自己的工具入口。拥有任意文件写入或 eval 的 Agent 可以绕过插件；Skill 不提供进程级隔离。严格场景由宿主只暴露包装器或受限工具。

修改通过一次编辑器事务，保留正常撤销。未打开笔记用 Vault.process 检查完整源文档再写。不同编辑缓冲区拒绝读取；多个内容相同但独立的编辑缓冲区也保守拒绝自动提交。

commit 的 applied 与 saveStatus 分开。unsaved 表示已进入编辑器而尚未观察到落盘；failed 应保留编辑器内容并复制到恢复笔记，或正常撤销。未打开文件的撤回通过界面“提交记录 → 预览撤回”，仅在源版本未变化时创建反向候选。

临时方案和回执默认仅在内存。重启会话改变，旧候选不能重用。当前版本不恢复临时草稿，不承诺跨设备或多进程事务。
