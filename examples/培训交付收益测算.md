# 培训交付收益测算

假设 10 名毕业学员持续接单 2 个月，每人每月完成 4 单。
仅计算接单交付环节，不包含培训、获客、管理等其他成本。

```notecalc
// @model training-delivery
// @version 1
// @input 每单单价 control=slider min=1000 max=3000 step=100
// @input 学生提成比例 control=slider min=0% max=100% step=5%
// @output 每单结余
// @output 组织方交付结余

总计划人数 = 20
培训周期月数 = 3
毕业人数 = 10
变现月数 = 2
每单单价 = 2000
每单词元成本 = 300
学生提成比例 = 50%
每人每月单量 = 4

毕业率 := 毕业人数 / 总计划人数
每单学生提成 := 每单单价 * 学生提成比例
每单结余 := 每单单价 - 每单学生提成 - 每单词元成本
总单量 := 毕业人数 * 变现月数 * 每人每月单量
总收入 := 总单量 * 每单单价
学生提成合计 := 总单量 * 每单学生提成
词元成本合计 := 总单量 * 每单词元成本
组织方交付结余 := 总单量 * 每单结余
```
