# NoteCalc 局部错误与排版验收

下面故意保留一行除零错误。正常收入、独立结果应继续显示；仅错误行和依赖它的行报错。

<!-- notecalc id=partial-layout -->

- 单价：`2000 元/单`
- 单量：`80 单`
- 正常收入：`单价 * 单量`
- 单行错误：`1 / 0`
- 关联结果：`单行错误 * 2`
- 长表达式结果：`单价 * 单量 + 单价 * 单量 + 单价 * 单量`
- 独立结果：`12 * 3`

<!-- /notecalc -->

代码块也采用相同规则：

// @model block-layout
